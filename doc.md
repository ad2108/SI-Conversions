# Definitions 

## to\_deka 

The function to\_deka converts all accesible formats to deka($10^1$) 

## to\_hecto 

The function to\_hecto converts all accesible formats to hecto($10^2$) 

## to\_kilo

## to\_mega

## to\_giga

## to\_tera
